# Sphinx Documentation Builder

This directory contains the Sphinx configuration for generating API documentation from Python docstrings.

## Building Documentation

To build the HTML documentation:

```bash
cd sphinx
make html
```

The generated documentation will be in `sphinx/build/html/`.

## Requirements

Install Sphinx dependencies:

```bash
pip install -r sphinx/requirements.txt
```

## Read the Docs

This configuration is used by Read the Docs for automated documentation builds.
